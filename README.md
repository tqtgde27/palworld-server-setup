## 搭建流程：三步开服，全程不碰命令行

搭建幻兽帕鲁服务器只需要三步：购买时选幻兽帕鲁应用模板，支付后到控制台确认公网 IP，然后把「公网IP:8211」发给朋友进服。不用登录服务器装 SteamCMD，也不用手动编辑配置文件。

### 第一步：购买时选对应用模板

腾讯云现在把幻兽帕鲁等游戏的一键开服收进了「轻量云·游戏服专区」，从专区的幻兽帕鲁入口进入购买页，镜像类型选「应用模板」，再选「幻兽帕鲁Windows」或「幻兽帕鲁Ubuntu」。

- Windows 版带图形化界面，适合没接触过 Linux 的玩家
- Ubuntu 版占用系统资源更少，适合熟悉 Linux 的人
- 地域选离你和朋友近的，上海、广州、北京、成都、南京都有节点
- 时长按需选择，打算长期玩就别只买一个月，原因后面讲

支付完成后系统会自动部署服务端，你不需要再动手安装任何东西。

### 第二步：在控制台拿到公网 IP

进入轻量应用服务器控制台，找到刚买的实例，公网 IP 显示在实例信息里。腾讯云的幻兽帕鲁应用模板默认放通 8211 端口，不需要你手动配置防火墙规则。

### 第三步：朋友从 Steam 进服

1. 打开 Steam 客户端并登录，在「库」里找到幻兽帕鲁，点开始游戏
2. 游戏菜单选「加入多人游戏（专用服务器）」
3. 输入服务器的 `公网IP:8211`，比如 `175.xxx.xx.138:8211`，点联系

冒号必须是英文冒号。中文冒号会直接报 `Format Error`，这是新手最常卡住的地方。

## 开服后改参数：死亡不掉落、经验倍率怎么调

在轻量应用服务器控制台进入实例详情，点「应用管理」，就能看到幻兽帕鲁的游戏配置面板。改参数不用登录服务器，也不用碰配置文件。

以设置「死亡不掉落」为例：

1. 点面板里的「调整参数」按钮，表格进入编辑状态
2. 找到「死亡惩罚」配置项，把值改成「无丢失」
3. 点「保存」，弹窗会提示需要重启应用才能生效
4. 点「重启应用」，修改生效

面板打开时会读取当前最新的配置项，经验倍率、捕捉倍率、掉落倍率都在同一个表格里，改完保存再重启就行。保存后不重启，参数不会生效，这一步别漏。

## 内存溢出与定时重启：长时间开服的两个保命操作

幻兽帕鲁服务端存在内存泄漏，开服时间越长内存占用越高，严重时游戏会异常退出。腾讯云在应用管理面板里提供了两个一键操作，再加一个自动重启脚本，基本能覆盖这个问题。

### Windows 服务器：一键设置虚拟内存

在应用管理面板点「设置虚拟内存」，按规则填写：

- 服务器内存 ≤ 8GB：最小值设为内存的 1.25 倍，最大值设为内存的 2 倍
- 服务器内存 > 8GB：最小值 12GB，最大值 16GB
- 例如 4 核 8G 的套餐，就是最小值 10GB、最大值 16GB

系统盘可用空间必须大于虚拟内存的最小值，否则会设置失败。

### Linux 服务器：一键设置 Swap

Ubuntu 服务器点「设置Swap」，默认大小与内存一致，8GB 内存对应 8GB Swap。同样要求系统盘空间足够。

### 定时自动重启

腾讯云的教程提供了按内存占用比例自动重启游戏服务的脚本，配置完成后会按设定的时间间隔自动重启，把内存占用清回低位。配合虚拟内存或 Swap，长时间开服会稳很多。

## 常见问题

**Q：朋友进服需要我一直在线吗？**
不需要。这是云服务器开服和「房主直连」最实际的差别：服务器 7×24 小时运行，你下线了朋友照样玩。

**Q：连接时提示 Format Error 怎么办？**
最常见的原因是冒号打成了中文冒号。地址格式是 `公网IP:8211`，冒号要在英文输入法下输入。

**Q：朋友连不上服务器，先查什么？**
按顺序查三件事：地址是不是公网 IP（不是内网 IP）、端口是不是 8211、防火墙有没有放通 UDP 8211。腾讯云的幻兽帕鲁应用模板默认放通了这个端口，如果你手动改过防火墙规则，重点查这里。

**Q：最低配 4 核 8G 到底够不够？**
2–4 人短时间玩够用。但考虑内存泄漏和长时间挂机，4 人以上、或者你希望服务器开一整天不重启，4 核 16G 更稳妥。

**Q：现在游戏是 1.0 正式版，搭建流程有变化吗？**
开服流程没变，还是买带应用模板的服务器、确认 8211 端口、输入 IP 进服。1.0 正式版（2026 年 7 月上线）新增了世界树区域、多结局剧情等内容，官方建议开新档体验完整内容，旧存档可以继续使用。专用服务器联机上限为 32 人，对应 16 核 64G 这一档配置。

**Q：可以用自己的电脑搭服务器吗？**
可以，但家用电脑没有公网 IP，需要额外处理公网访问（比如内网穿透），而且电脑得长时间开着，断电断网就全员掉线。云服务器的价值主要在这里。

**Q：服务器以后能换别的游戏用吗？**
轻量应用服务器支持重装系统更换应用模板，但重装会清空系统盘数据，操作前先把幻兽帕鲁的存档备份出来。
